# 設計系統（slate 設計；2026-11-26 起新課的預設）

這一份寫投影片長什麼樣子、為什麼這樣設計、每一種元件怎麼用。色票與開關的值在 `templates/course.template.yaml`，程式在 `scripts/gen_pptx.py`、`scripts/flow_shapes.py`、`scripts/gen_lab_pptx.py`、`scripts/draw_flow.py`、`scripts/html_deck.py`。規則（字級、不編號、拆兩頁要重疊、括號裡的英文不變淡、圖的出處）仍在 `AGENTS.md` 硬規則 3、15、19–22；兩邊不一致時以 `AGENTS.md` 為準。

## 1. 緣由

- 2026-11-24：教師看了呼吸第二講的重設計版（照 Gemini 的設計規範畫）：「之後的課都以這個版面的大一號字版本為default」。這是字級、行距、標題直條與細線、照片白邊細框那一層，現在還在。
- 2026-11-25：流程圖六種排法輪流用、不編號、拆兩頁要重疊、括號裡的英文不變淡（硬規則 22）。
- 2026-11-26：中乙腎臟一的流程圖改善包，Gemini 除了改寫每一張流程圖，另外給了一份視覺設計規格與互動預覽。教師看了：「這設計看起來不錯 以後把這組設計當成default」；看了照它做的草稿3：「草稿三相當相當不錯 根據這個設計思維重新整理整個slidekit的設計吧!」。他同時定了兩點：**括號裡的英文不變淡**（規格建議變淡，他不要）、**流程圖的卡片照 Gemini**（白底細框）。

## 2. 設計思維（做新元件、挑排法時照這四條想）

1. **角色要一眼分得出來。** 一張流程圖裡有四種東西：一般的步驟、承上頁重複的那一格、箭頭上的機轉（為什麼會走到下一步）、終點（學生最該記住的結果）。四種各有固定的樣子，不靠讀字分辨。表格也一樣：表頭、首欄、資料格各有固定的樣子。
2. **線和字分開。** 箭頭是細的灰線，機轉寫在不透明的膠囊裡、壓在線上；線不穿過字，膠囊不和卡片的框黏在一起。
3. **形狀照病理的邏輯。** 單線的病程用直的排法；兩個原因造成一個結果、一個原因造成兩個結果、一個原因經兩條路加重同一個結果、會回頭的惡性循環、兩道關卡擋住同一個東西，各有對應的排法（第 4 節的表）。該並列的不要畫成一直線，該回頭的要有回頭的箭頭。
4. **終點呼應標題。** 最後一格是深色實心格，寫的是這一張標題要學生記住的那件事。一格只講一件事，最多兩行；放不下就拆成重疊一格的兩頁。

顏色只做兩件事：分角色（上面四種）與標重點（`[[橘:]]` 關鍵字、`[[藍:]]` 最該記的東西）。其餘是深板岩色的字、白色的卡片、微灰白的底。

## 4. 流程圖

開關：`layout.flow_look: slate`。每張圖在規格寫 `"style"`，沒寫用 `layout.flow_style`。九種排法，照流程的形狀挑，相鄰兩張不同種；同一個流程拆成兩頁時兩頁用同一種。

| 流程的形狀 | 排法 | 規格 |
|---|---|---|
| 單線，三格、每格一到兩行 | `stack`（直式卡片）或 `timeline`（時間軸，不加框） | 節點、箭頭交替 |
| 單線，三格都是一行、說明比較長 | `spine`（置中的卡片，說明掛在中軸線上） | 同上 |
| 剛好兩格 | `steps`（左右兩格） | 兩個節點；`"pill": "mid"` 把說明放中間 |
| 兩個原因或兩個條件 → 一個結果 | `merge` | 第一個節點的兩行各成一格 |
| 一個原因 → 兩個結果 | `fork` | 第二個節點的兩行各成一格 |
| 一個原因經兩條路造成或加重同一個結果 | `diamond`（菱形分合） | 節點（上）、箭頭（兩行＝左支、右支的說明）、節點（兩行＝左格、右格，格內換行寫 ⏎）、節點（下） |
| 最後一步回頭加重第一步（惡性循環） | `cycle`（直式卡片加左邊的回頭箭頭） | 和 `stack` 一樣，另寫 `"loop": ["回頭箭頭上的字", "第二行"]` |
| 兩道關卡依序擋住同一個東西 | `sieve`（雙關卡） | 和 `merge` 一樣（第一個節點的兩行＝兩道關卡），箭頭＝被擋回的東西，另寫 `"source": ["來源那一塊的字"]` |

共同的樣子：

- **一般的卡片**：白底、1.5pt 細框、左緣一條藍色帶（`stack`）。字 24–30pt，一格最多兩行。
- **箭頭與機轉**：灰色的線加箭頭；機轉寫在淺杏底、深赤陶粗字的膠囊，壓在線上。膠囊只寫「為什麼會走到下一步」，不重複格子裡的狀態。
- **終點**：最後一格深色實心、白色粗字。這一頁不是整個流程的終點時寫 `"end": false`。
- **承上頁**：`"carry": 1` 的第一格是淡藍底、藍色虛線框，右上角寫「承上頁」（16pt，和出處行同一類，`check_deck.py` 不報）。
- **不編號**（硬規則 22）。別家模型的參考有編號也不照抄。
- 一格三行或一頁超過三格（`timeline` 可以四格）：拆成重疊一格的兩頁，不縮字。
- 中醫的辨證路徑（`kind: stages`）是教師自己定的格式，不套這一節。

`cycle`、`diamond`、`sieve` 只有 `flow_look: slate` 才畫；沒開的課寫了這三種會退回最早的圓角框。

## 5. 表格

開關：`layout.table_style: slate`（整套統一；蓋過每張的 `tbl: style=`）。

- 表頭深色底、白色粗字；表頭下一條 2pt 深線。
- 資料列隔列淡底，列與列之間 1pt 淡線，表底 1.5pt 灰線；沒有直線。
- 首欄粗體、和內文同色。格子裡的 `[[橘:]]`、`[[藍:]]` 照樣上色。
- 欄寬、首欄英文換行（`tbl: first=stack`）、放不下拆張的規則不變（`scripts/README.md`）。表格張一定看算圖：LibreOffice 實排比估算高時最後一列會被裁掉（`tbl: fill=off`、`line=1.0`）。

## 6. 其他元件

- **標題**：靠左粗體，左邊一條藍色直條，下面一條細線。
- **說明句**（標題下、圖或表上面那一行）：`layout.lead_bar: true` 時左邊一條細的藍色直條，把「前提」和下面的本體分開。
- **照片與教科書的圖**：白邊細框（`layout.photo_mat`）；有可編輯標籤的示意圖不加框。底色不是純白，所以白底的圖會像一張白色的卡片，這是預期的樣子。
- **國考題**：題下那一行放進淡藍底的橫條，左邊一條藍線。
- **數字**：不做淡色底、框裡一個大字的數字卡（硬規則 21）；用沒有框的數字欄（stats 版型）、條列、表格或流程圖。流程圖與表格的白底細框卡片不算這一類。
- **封面與分隔張**：深板岩色底、右側色塊、橘色直條；版面不變。
- **實驗講義**：`gen_lab_pptx.py --style slate`（同一組顏色與表格樣式；圖框、字級與 rd 模式相同）。
- **HTML 版**：`html_deck.py` 與 `draw_flow.py` 讀同一組開關。`draw_flow.py` 給了 `--course` 就照用到那張圖的 deck 決定樣子（`--deck <deck>`、`--look slate|classic` 可以指定）；slate 的圖直接借 `flow_shapes.py` 的排版畫成 PNG，所以和 PPTX 同一個樣子。`html_deck.py` 看到 slate 的 deck 用到還沒重畫的舊圖會印 `[注意]`。Claude Slides 匯出（`to_claude_slides.py`）還沒有跟。
- **實驗講義的 HTML 版**（`html_lab_deck.py`）還是最早的樣子，沒有跟。

## 7. 沒有採用的（Gemini 規格裡有、我們沒有做）

- 括號裡的英文變淡：教師不要（硬規則 22）。
- 流程圖後面墊一條代表基底膜的橫帶（`cross_zone`）：要流程的格子裡真的有「穿過那一層」的步驟才對得上，遇到再做。
- 英文另用 Inter 字型：PPTX 的中英文都指定微軟正黑體（`check_deck.py` 會查字型），沒有改。
- 固定的座標：我們的流程圖是照字量出來排的（字級由大到小試，放得下的最大一級），不寫死座標。
