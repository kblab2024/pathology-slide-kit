# 22 條列與句型

## 摘要

授課教師的條列不是教科書式的名詞堆疊，而是把上課要講的話拆成短句：一張內容張通常 0–3 條（他自製大堂課 61% 的張沒有中文內文行，只有標題句＋圖；他親手新增的 41 張全部 ≤3 條），每條中文 10–30 字；疾病、細胞、解剖名與免疫標記在該套第一次出現就寫「中文(English)」；機轉用「會／可以／因此／造成」的因果句，=> 只留給 2–4 節的短鏈；定義用「先描述現象，句尾再稱為X(English)」；比較用同形的「標籤：內容」；Robbins 自己也不確定的事寫「目前認為／有可能」。他改我的稿時最一致的動作是補英文、把名詞片語改成有動詞的句子、加推測語與跨主題對照括號，並刪掉術語後面的預告式問句、條列尾巴的評論或勸學句、把疾病寫成攻擊者的「打的是／打這裡」，以及排名、年發生數、細胞比值這類與判讀無關的數字。他自己的格式（括號前空格、句號、大小寫、他／它、半形空格停頓、=> 與 →）不統一，檢查程式不得正規化。2026-09 課程 C（immune，牙醫系免疫疾病）的免疫 deck（我產，184 張，教師尚未改）是第一套照這些規則從零生成的 deck：使用者（教師）2026-09 明令「所有專有名詞「中文(English)」」（每張首見，見 24_術語與中英對照 TERM-34）、字不可小（課程 C 字級見 10_版面/12_字級 SIZE-29）、「不可 LLM 語」，兩輪審查又補出三條本檔原來沒有的教訓（一條條列要能單獨讀、不寫電報體壓縮、條列數與行數受管線版型容量限制），列為 BUL-36～38。本檔有多條規則與其他檔重疊，2026-09-25 依一致性審查改成「指標條」：等級、門檻與 regex 以被指的規則為唯一出處，本檔只保留條列面的證據（見規則節開頭的說明）。規則衝突時一律依權威順序：他親手改我的稿 ＞ 他自製 2026 ＞ 2025 ＞ 2024 ＞ 他對特定課程的明令（只在該課有效）＞ 我的毛胚（只當反例）＞ 他人（只當對照）。本檔所有計數的分母見統計表 S1：他自製語料逐張去重後 1,429 張（大堂課 900 張），2025_C_腫瘤_0809 是同事甲的檔，已剔除。

## 規則

本節先列總表，再依強度排列細則（MUST → NEVER → SHOULD → AVOID → MAY；同級依編號）。規則編號沿用挖掘檔，BUL-36～38 為本檔新增（來源：免疫 deck 審查與管線），編號不得重用。

指標條的讀法：標題或等級欄寫「唯一出處：XXX-NN」的規則是指標條。等級、門檻、regex 與替換表一律以被指的規則為準，本檔不另訂數字；本檔只保留條列面的正例、反例與改稿證據，被指的規則改版時不必同步改本檔。若本檔描述值與被指規則的門檻看起來不一致，照被指規則做。本檔是唯一出處的規則：BUL-07（每張條列數）、BUL-12（句尾短括號旁註）、BUL-06 的「單條鏈 ≤4 節」，其他檔引用本檔。

引文格式：「原文」（語料代號 #張號），原文逐字取自 <materials>/corpus/decks/<代號>.json；引文後的〔〕是本檔加的說明，不是原文。免疫 deck 的文字不在語料庫，寫成「原文」（免疫 deck 的 slug，審查編號），不用 # 號，也不是他的證據，只是「照本檔規則產出、經審查修正」的參考。「審查者」指免疫 deck 兩輪審查的 LLM 審查者與查核者，不是教師。

**生成一條條列時的套用順序（給 LLM）**

1. 先決定這張要不要條列（BUL-07、BUL-38）：能用一句標題＋圖講完就不寫條列；要寫時新寫 0–3 條，用管線時再照版型容量寫（13_密度與字數 DEN-27）。
2. 每條只講一件事，能單獨讀懂（BUL-36），中文 10–30 字、不用「；」串兩件事（BUL-08；總長上限見 DEN-06、DEN-19）。
3. 寫成有動詞的講課句（BUL-02），條件與主體寫完整，不壓成電報體（BUL-37）；分類清單與比較才用「標籤：內容」（BUL-03、BUL-26）。
4. 第一次出現的專有名詞寫「中文(English)」（BUL-01，門檻見 TERM-07；課程 C 每張首見見 TERM-34）。新術語先描述、句尾再命名（BUL-04）；形態寫看得到的東西（BUL-05）；不確定的寫「目前認為」（BUL-28）。
5. 機轉用因果句，=> 只留給 2–4 節的短鏈（BUL-06；數量上限見 SYM-04）；數字只留能接對比或決策的（BUL-13、BUL-14）；括號只做舉例、白話、對照、限定（BUL-12）。
6. 最後掃一遍禁區：全形雙破折號與 LLM 轉折（BUL-16）、術語後的預告問句（BUL-09 → TTL-38）、評論或勸學尾句與臨床命令（BUL-10 → BAN-09、BAN-13）、「打的是／打這裡」（BUL-11 → BAN-05）、翻譯腔（BUL-15 → TERM-33）、自寫英文敘述條列（BUL-25）。
7. 他自己不統一的格式（BUL-24）與口語詞（BUL-30）不要去改，也不要讓檢查程式報錯。

## 常見錯誤

生成時最常出現、而他會刪或改的寫法（左＝不要，右＝要；引文見對應規則）：

1. 術語首見沒有英文，或只在標題補、條列不補 → 首見就寫「中文(English)」（BUL-01，門檻見 TERM-07）；課程 C 每張首見（TERM-34）。
2. 名詞判斷句「p16 強陽性，為 HPV 替代標記」→ 推論句「因此P16…可以當作 HPV感染的間接證據」（BUL-02）。
3. 把他現成的動詞講課句改寫成「X：Y」標籤 → 逐字沿用他的句子，只補英文（BUL-02、BUL-03）。
4. 標題「術語：栓子從哪裡來」「什麼叫做癌前病變？」→ 純術語標題，或「何謂X？答案」（BUL-09；唯一出處 TTL-38）。
5. 條列尾巴加評論「所以一定要認出來」「也是四問的第一個答案」，或對讀者下臨床命令「應使用」「要及時拔」→ 刪尾句，只留事實；臨床建議寫「指引建議…(出處)」（BUL-10；唯一出處 BAN-09、BAN-13）。
6. 「X打的是…」「…打這裡」「可以回頭的」→「病灶主要在…」「發生位置」「為可逆的」（BUL-11；唯一出處 BAN-05）。
7. 「全世界第六常見、每年 65 萬例」「CD4/CD8 比值 5:1 到 15:1」→ 刪；只留接得上對比或決策的數字（BUL-14）。
8. 用一串 => 取代整段機轉，或鏈尾再掛第二件事 → 因果句；=> 只留 2–4 節短鏈（BUL-06；每張與每套數量見 SYM-04）。
9. 一條條列用「；」串兩件事，或括號裡塞圖例英文 → 拆條或刪括號（BUL-08、BUL-12）。
10. 把一個句子拆成兩條，後一條「通常就是…」「只有…」沒有主詞 → 併成一條（BUL-36）。
11. 為了省字寫「可免」「易復發」「至少一臨床一免疫」「單純細胞排斥」→ 寫完整的條件與受詞，放不下就拆張（BUL-37、BUL-38）。

13. 無承接的「不過，」開頭 → 刪；有推導鋪陳時反而可以加「因此」（BUL-17；比例門檻唯一出處 TTL-09）。

15. 數字卡、兩位小數、「只有 22%」這類評價性數字 → 一行一個判斷的句子，數字取整、放句內（BUL-13）。
