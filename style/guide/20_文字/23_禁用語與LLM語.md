# 禁用語與 LLM 語

## 摘要

他自製的 1251 張唯一張裡，37 個常見的 LLM 論述套語（此外、換句話說、值得注意的是、關鍵在於、其一其二…）、全形雙破折、舞台指示、「總結／回顧／學習目標」類標籤與打氣喊話全部是 0，所以這些列 NEVER（課程 C 另有使用者（教師）2026-09 明令「不可 LLM 語」，見 immune/brief.md；點名班別同樣是 0，但等級以 38_課別差異 AUD-30 的 AVOID 為準）；但要記得它們是缺席證據，沒有一條是他改稿時刪過的。他真正動手刪改的，是我毛胚裡的另一類東西：口語位置動詞（打這裡、打的是、可以回頭）、「術語：問句尾」標題、貫穿全套的口號類比（長在裡面的皮膚）、戲劇化的評語尾巴（所以一定要認出來、決定膿瘍長在哪裡）、翻譯腔直譯（IgE 交聯、一群異質性疾病）、「X序列：」標籤、「詳見第 N 章」、教科書後設語、「第二講：」與「異型增生」；這些列 AVOID 或 SHOULD，而且他常只改到他重讀的那一行，定稿裡留著我的殘渣，所以檢查器對他的定稿只能 WARN，也不能拿他的定稿當反例。反過來，其實、實際上、真的、我們、你、叫做、東西、導致、擬人動詞（求救、召喚）、自答型問句標題、括號旁註與國考複習裡的「考死背」都是他的本色，v2 誤禁的要放行；我的三份毛胚與 2026-09 的免疫牙醫系成品在這些詞上都遠低於他的頻率，比他還正式（免疫成品 169 張非考題張「導致」0 次、「因此」0 次、「造成」17 張）。免疫成品另外教了三件事：撰寫批次 check_written RED 0、成品 style_check RED 0 的版本，人工審查仍抓出本主題的命令句、句尾揭曉、後設指代、新聞標題式排名、電報體、翻譯腔與管線備忘，所以機械檢查只是門檻；詞表會誤報（「回顧」指 review 文章、「猛爆性齲齒」是術語、「工廠汙染」「砌磚頭」是他的原句），規則要寫成詞組而不是單字；管線的備忘與標籤不能漏進備註。最後，檢查器必須跳過貼入的國考題與英文原文，「每套 ≤N」的門檻以唯一句或同標題連張計，否則會把他自己的檔判錯。

**權威順序**（規則衝突時照這個順序取捨，同 01_權威順序）：教師親手改我的稿（2026_B2 三套）＞教師自製 2026＞2025＞2024＞教師對特定課程的明令（只管該課程，例如課程 C 的字級）＞我的毛胚（只當反例）＞他人（同事甲，只當對照）。CLAUDE.md 文風節是 ENT 專案規格 v3，由我們從他的改稿歸納而來，不是他逐項下的明令，也不能外推成所有課別的權威；本檔每條的等級都以語料證據支撐（例如 0/1251），CLAUDE.md 只在「適用範圍」標為旁證。「使用者（教師）2026-09 明令」只用在 immune/brief.md、immune/course.yaml 與計畫檔裡他逐項裁決的事，而且只管該課程（課程 C）。CLAUDE.md 與他的投影片衝突時（例如 CLAUDE.md 把「磚」「工廠」「這張」列入禁用，他自己卻寫「砌磚頭」「工廠汙染(砷)」、「這張」多半是量詞），以他的投影片為準，只禁 CLAUDE.md 真正針對的詞組。

**讀法**
- 引文一律寫成「原文」（代號 #張號），可用 `scripts/verify_quotes.py` 逐字核對；「↵」是投影片內的軟換行（U+000B）。免疫成品與審查檔不在語料庫，引用時標（immune 成品 #N）或（immune 審查 roundN voice-NN），不走逐字核對；張號是 2026-10-02 版 184 張的編號，審查檔內的「舊 #N」是當輪編號。
- 分母：他自製 31 檔、忽略頁碼整張文字去重後 1251 張唯一張（講述張 1020、類考題張 149、無中文 82）、唯一備註 78 段；改稿 317 張；我的毛胚 417 張；他在改稿親手寫的 + 行 365 行；免疫成品 184 張（國考題 15、非考題 169）。本檔新查的詞（BAN-03、BAN-04 的補列與 BAN-34、BAN-35）以同一去重法重掃，得 1250 張（與 1251 差 1 張，屬頁碼段判定差異），細節見 S1。
- 等級：MUST／NEVER＝交付前必須做到或必須為 0；SHOULD／AVOID＝預設照做，他的定稿有殘留，所以對他的檔只 WARN；MAY＝放行，檢查器不得報錯。「FAIL」＝rules.yaml 的 RED。
- 同一件事在別的面向另有規則時，本檔只管「這個詞能不能寫」，格式細節照被引用的檔。
- 唯一出處：一件事只在一條規則裡定義等級與門檻。下列本檔條目只是索引或別名，等級、門檻、regex 照括號裡的規則，本檔不另訂：BAN-01（24 TERM-02）、BAN-06（21 TTL-38）、BAN-10 的替換表（24 TERM-33）、BAN-16 的作答距離與頻率（26 TONE-03）、BAN-17 的括號規格（22 BUL-12）、BAN-18 的「=>」數量（25 SYM-04）、BAN-20 的首見覆蓋率（24 TERM-07；課程 C 見 TERM-34）與縮寫分隔符（25 SYM-17）、BAN-21 的檢查範圍（24 TERM-04）、BAN-23 的句首「不過」上限（26 TONE-09）、BAN-28 的收尾張、目次張與範圍表（31 OPEN-02、OPEN-22、OPEN-13）、BAN-31（31 OPEN-21）、BAN-33（25 SYM-22）、BAN-34 的班別稱呼（38 AUD-30）、BAN-08 的整張標題用法（16 CITE-23）。反過來，BAN-03（LLM 套語詞表）、BAN-05（口語位置動詞）、BAN-09（戲劇化包裝）、BAN-13（命令、臨床祈使句與新聞式排名）、BAN-24（首先／其次）是唯一出處，別檔引用本檔。語氣類能判 FAIL 的清單以 26_語氣與態度 TONE-35 為唯一出處。

## 常見錯誤

生成或檢查時最常犯的錯，左邊是錯、右邊是對。前半是寫稿端，後半是規則與檢查器本身的錯。

**寫稿端**
1. 把禁用詞換成另一個 LLM 詞（此外→除此之外、進而→從而、事實上→實際情況是）。→ 照 BAN-29 的替代表換成他的詞（另外、=>、其實），或乾脆刪掉連接詞。
2. 名詞句尾加評語或懸念：「名字叫非特異性，預後卻遠優於 UIP，所以一定要認出來」（mine_lung_B2二_0919 #31）。→ 平鋪「預後遠優於 UIP」（2026_B2_呼吸系統病理二_0920 #33）；對照放括號旁註（BAN-09、BAN-17）。
3. 句尾代名詞揭曉：「修格蘭症候群(Sjögren syndrome)最常合併的就是它」（immune 審查 round1 voice-18）。→ 直接寫出主角：「續發性修格蘭症候群(secondary Sjögren syndrome)最常合併類風濕性關節炎」（immune 成品 #82）。
4. 位置講成攻擊：「氣喘打的是支氣管壁的平滑肌，而且阻塞是可以回頭的」（mine_lung_B2二_0919 #3）。→「氣喘病灶主要在支氣管壁的平滑肌，為可逆的阻塞」（2026_B2_呼吸系統病理二_0920 #3）（BAN-05）。
5. 標題掛預告問句：「肺栓塞(pulmonary embolism)：栓子從哪裡來」（mine_lung_B2二_0919 #50）。→ 純術語「肺栓塞(pulmonary embolism)」（2026_B2_呼吸系統病理二_0920 #54），要問就寫自答型（21 TTL-38、26 TONE-03；本檔索引 BAN-06、BAN-16）。
6. 全套反覆一個口號類比（長在裡面的皮膚、這條路的最外層）。→ 類比只在一段 build，第一張寫明「把 X 想成 Y」（BAN-07）。
7. 臨床建議寫成命令：「滯留的乳牙要及時拔」（immune 審查 round1 voice-31）。→ 標題寫病理事實「高IgE症候群(Job syndrome)：乳牙常沒有牙根吸收(root resorption)」（immune 成品 #142），建議寫「指引建議…(出處)」（BAN-13）。
8. 標題用「這三種」「這些」指張上的條列。→ 名詞化標題「容易長淋巴瘤(lymphoma)的三種病」（immune 成品 #143）（BAN-14）。
9. 新聞標題式排名與趨勢（降到 N 年以來最低、全世界第六常見）。→ 標題寫張上數字支持的事實，趨勢與排名留講稿（BAN-13）；排名與年發生例數的處理另見 13_密度與字數、16_出處。
10. 直譯英文句構（一群異質性疾病、IgE 交聯、用了任何預防藥、…的病毒感染與腫瘤細胞）。→ 他的白話（表現各異的疾病、IgE 聚合、不論用哪種預防藥）（BAN-10）。
11. 電報體箭頭鏈當標題（形成 => 沉積 => 發炎與損傷）。→ 有主詞的句子，或拆成連張（BAN-18、22_條列與句型）。
12. 在文獻數字前加評價性的「只」（只有 22%、只報告 29 例）。→ 直接寫數字；這條的語料依據弱（他自己寫「高達七成」），列在這裡當提醒，不做檢查。
13. 講稿裡寫給教師或流程看的話（待教師決定、round1 審查後…）。→ 待裁決事項只進交教師清單（BAN-35）。
14. 放行詞一概不用，整套比他正式（免疫成品導致 0、因此 0、造成 17）。→ 照 S3 的頻率自然使用其實、所以、因此、導致、叫做（BAN-15，OQ-10）。
15. 模仿他定稿裡的殘留（打這裡、序列：、顯微鏡標誌、並非、膠原）。→ 那是他沒改到的我的字，生成時用他改過的版本（S5）。
