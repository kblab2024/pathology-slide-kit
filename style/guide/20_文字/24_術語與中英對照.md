# 術語與中英對照

## 摘要

授課教師寫術語的底層格式很穩：中文在前、英文放半形圓括號、中英同一段同一字級，他自己打字時括號前不留空格；括號內英文的大小寫、縮寫分隔符（逗號、分號、空格、全形逗號）、括號後的冒號、希臘字母這些細節他完全不校正，所以生成時選一種寫法用到底即可，檢查腳本不可以把他的變體判錯。他改我的稿時對照增多刪少：三次改稿的對應張內新增 101 個、移除 37 個，移除的幾乎都隨句子、框架圖圖例或出處一起刪，句子留下只拿掉英文的術語只有 2 個；唯一系統性的「留句子、拿括號」是刪掉句尾的非 Robbins 教科書出處。他會把我只寫英文的亞型補成「伏壁型(lepidic)」、把只給縮寫的補全名（DIP），也會把縮寫補在全名後面（CIS、HAP），還會把我直譯的學術腔改成上課的白話（IgE 交聯改聚合、一群異質性疾病改表現各異的疾病），但他不會每句都給英文（他親手寫的段只有 46% 含對照），通用縮寫（HPV、EBV）整套裸用。染色名、CD、Ig 類別、HLA／MHC、基因名只寫英文；標記與蛋白生成時一律大寫 P53／P16／P40／P63（檢查只查染色語境）；dysplasia 一律「分化不良」，這是他唯一逐字替換過的術語。他的錯字與術語疑點（白班、cilitated、肺容積(vital capacity)）依情境處理：回灌照留，搬句進新 deck 時英文與術語改正、中文用字照留，每一處都列清單交他裁決（TERM-18 決策表）。新寫文字不用斜體，菌種與基因名也寫正體；染色性質寫「嗜酸」「嗜鹼」，不寫 Robbins 中譯的「嗜伊紅性」。2026-09 他對課程 C（immune，牙醫系免疫疾病）另下明令「所有專有名詞「中文(English)」」與字級下限，這只管那一門課；那門課用 glossary 驅動，兩輪審查找到的術語問題幾乎都是圖標籤、框架圖格子、表格儲存格漏英文，以及正名被插字或括號切開而讓檢查器看不到。舊版把「中文 (English)：定義」當 LLM 指紋而禁止，已證實他自己常用，改為允許。

## 權威順序與衝突處理

本檔的規則互相衝突時依下列順序取捨（同 01_權威順序）：

1. 他親手改我的稿（2026_B2 三套）。
2. 他自製的課，2026 ＞ 2025 ＞ 2024。
3. 他對特定課程的明令（例如課程 C 的「每張中英」與字級），**只管該課程**。排在語料之後的意思是：不能拿它改寫從他的改稿與自製課推出的一般規則，也不外推成他的習慣；但它是該課程的規格，在該課程內照做（TERM-06、TERM-27、TERM-31 在課程 C 讓位給 TERM-34）。
4. 我的毛胚只當反例；同事甲與貼入表格只當對照。

本檔已知的衝突點：TERM-34（課程 C 每張中英）對 TERM-06（不必每句重標）、TERM-27（通用縮寫裸用）、TERM-31（圖標籤並列不加括號）；天皰瘡／天疱瘡（他親手寫前者、課程 C glossary 用後者，交他裁決，見 TERM-15 與待教師確認第 5 題）；TERM-05 的分隔符自由（檢查端）對生成端全套固定用「, 」。

等級意義：MUST＝違反會被他改、造成回灌不一致，或違反他對該課程的明令；SHOULD＝強烈傾向，偏離要有理由；MAY＝他的可選寫法，可以用；AVOID＝不要生成（他自己偶爾有，回灌不改）；NEVER 本維度無。規則依等級排列（MUST → SHOULD → AVOID → MAY），同等級內證據強的在前；編號沿用 mining 版，新增的是 TERM-33～38。等級欄只放一個字；課程或管線的升級一律寫在「適用範圍」欄，格式為「課程 C：MUST（使用者（教師）2026-09 明令，見 TERM-34）」或「管線規則，不是他的習慣」。

## 常見錯誤

依出現頻率排列；左邊不要，右邊要。

1. **圖標籤、框架圖格子、表格儲存格漏英文**（課程 C 兩輪 25 條：round1 14、round2 11）：`顎下腺 H&E` → `顎下腺(submandibular gland) H&E`；`腎炎、皮膚病灶、關節炎` → `腎炎(nephritis)、皮膚病灶、關節炎(arthritis)`。這些位置 style_check 不掃，一定要看渲染後的 PNG（TERM-34）。
2. **只寫中文、該補的英文沒補**：「• 氣道血管增加、黏膜下腺體增大與杯狀細胞增生 => 管腔黏液堆積」（mine_lung_B2二_0919 #10）→「• 氣道血管增加、黏膜下腺體(submucosal gland)增大與杯狀細胞(goblet cell)增生 => 管腔黏液堆積」（2026_B2_呼吸系統病理二_0920 #10）（TERM-07）。
3. **只寫英文、不給中文**：「腺癌的生長型態：lepidic、腺泡、乳頭、微乳頭、實質」（mine_lung_中醫系毛胚_0910 #43）→「腺癌的生長型態：伏壁型(lepidic)」（2026_B2_呼吸系統病理一_0913 #43）（TERM-07、TERM-16）。
4. **縮寫只給一半**：只寫 (DIP) 沒全名、只寫全名沒 (HAP)；兩者都要，縮寫放後面（TERM-05）。
5. **寫「異型增生」**：一律「分化不良(dysplasia)」，連我們自己的備註也不寫（TERM-02）。
6. **p16、p53 小寫出現在染色句**：「• p16 免疫組織化學染色強陽性，為 HPV 替代標記」（mine_ENT_中醫系毛胚_0906 #37）→「• 因此P16 免疫組織化學染色可以當作 HPV感染的間接證據」（2026_B2_頭頸部_0907 #39）（TERM-04、TERM-21）。
