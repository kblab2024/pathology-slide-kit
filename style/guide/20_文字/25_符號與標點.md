# 符號與標點

## 摘要

授課教師的標點是「半形當骨架、全形當中文句的肉」，而且他不在乎統一：術語括號、「=>」、「=」、「/」、「%」用半形，中文句的逗號、頓號、冒號、引號用全形；但他自己的檔同時有約 4% 全形括號、9% 半形標籤冒號、兩成多半形問號、括號前空格與不空格各半，而他改我三份稿的 245 條修改行裡沒有一條是只改標點的。所以本檔分三層。第一層是少數硬規則：不用全形雙破折號、百分比「70%」緊貼、漢字後不接半形逗號句點、推論箭頭只用 ASCII「=>」（不用 ⇒、->）。第二層是一組生成預設：從零新做的 deck 一張 ≤2 條「=>」鏈、含「=>」的張 ≤10%（B2 改寫型不設上限）、半形括號、全形冒號、標題與短標籤不加句號、條列不用「；」串子句、頓號列 2–4 項、計數用中文數字、數值範圍用半形「-」、問句要在同張或下張給答案、出處括號前留空格、括號不巢狀。第三層是一張「他這樣寫也對、檢查器不得報錯」的容忍清單：半形「: 」、半形「?」、「(English，ABBR)」、全形「／」、括號前空格、句中空格停頓、「 - 」副標、表格格內的「；」。生成新稿照預設寫；回灌或檢查他的檔時一個標點都不改（SYM-29）。2026-09 為牙醫系 C 班做的免疫疾病稿（184 張，還沒經他改）照這些預設生成，符號層幾乎沒被兩輪審查挑出錯；審查抓到的是另一類問題：產生器沒標中文語言，行首出現「，」「：」與孤立括號；行尾標點懸掛到圖上；題庫的分離式分音符把 Sjögren 畫成「Sjo¨gren」；我自己寫的縮寫分隔符前後不一；一個巢狀括號標題；以及為了避開行首標點，把他原句的逗號換成空格、把他的半形問號換成全形。前三項是排版與編碼問題，本檔新增 SYM-37、SYM-38；其餘併進對應規則。所有計數的分母見 S1：他自製 19 套（大堂 12、國考複習 5、實驗 2，已去重；2024 免疫一／二只算他自製的前段）、他改我稿的成品 3 套、我的毛胚 3 套、他人對照 2 套；免疫稿的數字另列 S12，只當反例與教訓，不當他的習慣。

引文格式：「逐字引文」（語料代號 #張號）。引文中的「⏎」代表 PowerPoint 段內軟換行（\v，python-pptx 讀出來是 \x0b），不斷行空格（\xa0）顯示為一般空格；探勘 JSON 保留原字元。免疫稿不在語料庫裡，它的文字一律用反引號加素材池 slug 標示（例：`imm-s1-005-innate-receptors`），不用語料引文格式，`verify_quotes.py` 不檢查它們。全形雙破折號在本檔一律寫成「全形雙破折號（U+2014 連寫兩個）」，不直接打出來。

## 權威順序與衝突處理

本檔的規則互相衝突時依下列順序取捨（同 01_權威順序）：

1. 他親手改我的稿（2026_B2 三套）。只算他親手打的字（edits/*.md 的 + 行扣掉同張 − 行已有的，加上他新增的張）；他「沒刪、原樣留下」的我的字只算容忍，不算他的寫法。
2. 他自製的課，2026 ＞ 2025 ＞ 2024。
3. 他對特定課程的明令，只管該課程。課程 C（牙醫系免疫）與本維度有關的明令只有一條：「所有專有名詞「中文(English)」」（immune/brief.md 教師已裁決表，使用者（教師）2026-09 明令）。半形括號、括號前不留空格、縮寫用「, 」分隔這些細節是我在 glossary 訂的一致性慣例，不是他的明令，也不外推成他的習慣。
4. 我的毛胚只當反例；同事甲與貼入的講義表格只當對照。

本檔已知的衝突與處理：

- SYM-02（新寫用半形括號）對他自己檔裡約 4% 的全形括號：他 2026 親手打的括號 97 : 0 全是半形（第 1 層），所以新寫用半形；他既有檔的全形括號屬第 2 層的容忍，回灌不改。
- SYM-05（他自製版型不手打條列字元）對他改稿時照我模板打「• 」：第 1 層推翻原探勘版的 NEVER，改成依版型分流。
- SYM-17（括號內縮寫四式並存）對課程 C glossary 固定「, 」：四式都出自他手，檢查器一律不報錯；生成新 deck 時全套固定用「, 」（他的主式，69 處；課程 C glossary 同）。
- SYM-04 的數量門檻對他核定的 B2 呼吸兩套（含「=>」的張 21.4%、23.9%，一套 42、44 個）：第 1 層（他親手核定）高於數量預設，所以「=>」的數量只對從零新做的 deck 當 SHOULD（WARN），B2 改寫型與回灌他核定的 deck 不設上限；MUST 只落在箭頭字元（ASCII「=>」、不用 ⇒／->）。
- SYM-15／SYM-29（他的原句一字不改）對免疫稿為了版面把他原句的逗號改成空格、問號改成全形：第 2 層（他的原句）高於版面便利，這類改動要列進待教師裁決清單，不靜默改。
- SYM-35（括號不巢狀）對 immune/成品/待教師裁決清單.md E7 的說法「您用過的巢狀括號」：語料重掃，他自製 19 套非引文的巢狀括號 0 處，E7 的描述與證據不符，本檔以語料為準。
- SYM-09（阿拉伯數字留給代號）對章號：他自己打的章號是中文數字（Robbins 第八章），我毛胚的「第16章」他改稿時沒動（容忍）；兩式都不算錯，新寫預設跟他自己打的中文數字，課程 C 的「第6章」待他裁決（D6）。
- 產生器與檢查器層（SYM-31、SYM-37、SYM-38）不是他的風格，是讓他的風格正確顯示、讓檢查器不誤判的技術前提，不和任何風格規則競爭。

## 規則速查

規則依強度排列（NEVER → MUST → SHOULD → AVOID → MAY），同等級內證據強的在前；編號沿用探勘版，SYM-37、SYM-38 是本版依免疫稿新增。等級意義：NEVER＝他的語料 0 次且出現即不得交付；MUST＝違反會被他改、造成顯示錯誤或檢查誤判；SHOULD＝生成預設，偏離要有理由，檢查只 WARN 或 INFO；AVOID＝不要生成，但他自己偶爾有，回灌不改；MAY＝他的可選寫法，可以用，檢查不得報錯。

## 規則

### SYM-01 投影片與備註不得出現全形雙破折號（U+2014 連寫兩個）；單一「—」只准用在古籍或名言引文的出處行（引文後軟換行，行首寫「— 《書名》…」），其他位置改用「 – 」、「=>」或改寫成句。

- 等級：NEVER
- 門檻：全形雙破折號＝0（FAIL）；單一「—」只出現在出處行行首（每套 ≤5）
- 適用範圍：所有畫幅、所有課別；標題、內文、表格、備註、講稿、講義補充都適用
- 他的正例：
  - 「「黑膽汁過多會導致絕望與恐懼的情緒，這稱為憂鬱。」⏎— 《箴言錄》希波克拉底(460BC-370BC)」（2026_A1_病理學簡介_0916 #13）
  - 「「溫邪上受，首先犯肺，從衛入氣，入營及血。」⏎— 《溫熱論》1746AD」（2026_A1_病理學簡介_0916 #21）
  - 「腹水(ascites) – 水在腹腔 算一種effusion」（2026_A2_血液動力學一_0317 #29）
- 我的反例：無。我的三份毛胚本來就是 0，免疫稿 184 張（含講稿與講義補充）也是 0，被 style_check 的 RED 擋在產出前；本條是防回退。
- 機械檢查：先把 \x0b 換成 \n；regex FAIL：`—{2}`；regex WARN：`—`，但 `(^|\n)—\s?(《|[^\s《]{1,12}\()` 這種出處行行首不報。canonical id 是本條 SYM-01；23_禁用語 BAN-02 為別名；v0:SYM-01（RED、scope all，備註也查）與本條同義。
- 為什麼：他自製 19 套（12 大堂＋5 複習＋2 實驗，去重後）、他改我稿的 3 套成品、我的 3 套毛胚，全形雙破折號全部是 0。單一「—」只在 2026_A1_病理學簡介_0916 一套出現 5 次（#13、#14、#21 兩處、#25），每一處都在引文後的軟換行之後、接《書名》；同套另有半形寫法做同一件事：「- 希波克拉底(460BC-370BC)」（2026_A1_病理學簡介_0916 #17）。全形雙破折號是 LLM 中文的標誌符號，他從不用（與 23_禁用語 BAN-02、21_標題 TTL-18 一致）。免疫稿的 writer brief 把它列為 RED 符號表的第一項（WB-15），要接亞型時改用「 – 」（SYM-12）或冒號（SYM-03）。
- 證據強度：全形雙破折號 0/25 套（他 19＋改稿 3＋我 3）；免疫稿 0/184 張；單一「—」1/19 套、5 處、單一用途
- 例外：引文出處行可用「— 《…》」或同一行半形「- 人名(年代)」；對照組 2025_C_腫瘤_0809 的「mir34a—mir34c」不是他的檔，不當證據。
