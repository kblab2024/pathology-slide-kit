# 開場與結尾

## 摘要

他的投影片沒有儀式。封面只有課名：不署名、不寫日期、主題課不放圖（24/24 份無署名）。第 2 張就進主題，沒有學習目標、沒有自我介紹，2026 年自製的檔也沒有條列大綱。結尾停在最後一個內容張：24 份（自製 15、國考複習 6、改稿 3）沒有一份有總結、Take home、謝謝或參考文獻，改稿時他還把我的兩張收尾（框架圖回顧、篩檢呼籲）整張刪掉。開場他最常做的是先鋪一段正常構造或正常生理（主題課 7/10），用同標題連張把複雜度攤開，再用「不過，…其實…」或 N 分法收斂成一個框架；改我的稿時，他把總覽提到第 2 張、刪掉開場條列裡的疾病預告、給每張開場張補一張真實切片，而不是刪字（呼吸一 #2–10 有圖從 1/9 變成 7/9）。國考定位張在主題課只是選項（2/6），在國考複習是常態（6/6）；第一題國考題放在開場段內（6/6 在 #27 以前），段落常以國考題收尾再接 divider（連放題數見 34_國考題 EXAM-06）。一章分兩講時，每講停在一群疾病的最後一張（常是結局或死因），下一段整段移到下一講開頭，第二講第 2 張直接進新主題；前後講的銜接只寫在備註或標題括號。從零做 4:3 主題課時，封面用內建「標題投影片」54–60pt、主標「病理學：主題(一)」；沿用我的 B2 模板改稿時他不換版型，所以那條只到 SHOULD。

2026-09 為牙醫系 C 班做的免疫疾病稿（184 張，一個檔涵蓋三節，尚未經他改）是第一套照這些規則從零做的 deck，和開場結尾有關的教訓有五個。(1) 他對這門課明令一個檔三節、節間用 divider、每節以 40 分鐘講完（他「從來不想把時間上滿」）、正常免疫只精簡複習 10–15 張、牙醫師國考題就近放；本檔把節界寫成新條 OPEN-38，並在 OPEN-07、OPEN-09 標出 C 班的明令。(2) 第 2 張定位張初稿做成三張 KPI 數字卡，審查改回他那種一行一句的大字；「國考重要性：○」這類判斷句只能由他下，稿上留白並列入裁決清單（OPEN-06）。(3) 第一題原本放在還沒教到答案的位置、又是純微免題，審查把它移走；第一題要能用前面幾張作答（OPEN-09）。(4) 在各節開頭重播的五大類框架圖，把格子裡兩個事實錯誤複製了三次，因為框架圖格子不在 style_check 的掃描範圍（OPEN-25）。(5) 封面致謝不取代圖下出處，出處欄裡的「封面已致謝」這類內部備忘被印上投影片（OPEN-10）。封面字級（44pt，他的是 54–60pt）、致謝行字級、節首框架圖算不算大綱，都還待他裁決。

## 讀法（先看）

- 引文一律逐字取自 `<materials>/corpus/decks/*.json`，格式「原文」（語料代號 #張號）；「↵」代表投影片內的軟換行（U+000B）；「 / 」分隔同一張的不同段落；引文後標「：備註」者是投影片備註裡的文字。可用 `scripts/verify_quotes.py` 核對。
- **權威順序**（規則衝突時一律照這個順序裁決）：他親手改我的稿 ＞ 他自製 2026 ＞ 2025 ＞ 2024 ＞ 他對某門課的明令（只管那門課）＞ 我的毛胚（只當反例）＞ 他人（只當對照）。
- **「使用者（教師）2026-09 明令」**：他對牙醫系 C 班免疫疾病直接下的指示，出處是 `immune/brief.md` 的「教師已裁決」表與 2026-09-24 計畫檔的「使用者已裁決」表：一個 4:3 檔涵蓋三節、約 180 張（每節約 60 張，55–65）、節間用 divider、每節以 40 分鐘講完；牙醫師國考題全套約 10–15 題、每節 3–5 題、就近放在該主題後 1–2 張；正常免疫精簡複習 10–15 張；Robbins 11e 第6章是唯一正典；不可 LLM 語；標題 36pt、內文 28pt、學生要讀的字 ≥20pt、出處 14pt；所有專有名詞「中文(English)」。在 C 班照做；推到其他班時不算他的習慣，他的 deck 習慣優先。
- **「免疫稿經驗」**：我 2026-09 產的 C 班免疫疾病稿（`immune/成品/病理學C_免疫疾病(PPTX)_20261002.pptx`，184 張）與兩輪審查（`immune/_archive/review/round1`、`round2`）、待教師裁決清單的發現。這份稿還沒經他改，屬「我的毛胚」層：只能當反例與流程教訓，不能當他的正例。免疫稿不在語料裡，引用時寫「第 N 張」與素材池 slug（張號以 2026-09-25 待教師裁決清單為準），不用引文格式。
- 分母代號：OWN＝他自製 15 份（主題課 10、簡介 3、實驗課 2）；REVIEW＝國考複習 6 份；EDIT＝他親手改我的稿 3 份；MINE＝我的毛胚 3 份；OTHER＝他人 2 份。去重與排除見〈統計表〉S1。
- 等級：MUST＝必須；NEVER＝禁止；SHOULD＝應該，偏離要有理由；AVOID＝避免，偶爾可以；MAY＝他用過、可選用。等級欄只放一個詞，取該條對一般課程的等級；某門課因明令升級時，寫在「適用範圍」欄，格式固定為「課程 C：MUST（使用者（教師）2026-09 明令，…）」。
- ID 沿用探勘版（`<materials>/style_evidence/mining/31_開場與結尾_final`）的 OPEN-01 到 OPEN-37，其他指南檔的交叉引用都指這組號碼；OPEN-38 是本版新增。規則依等級（NEVER → SHOULD → AVOID → MAY）排列，同等級內依證據強弱排列。
- `style/rules.yaml` v0 沒有任何 OPEN 前綴的規則，`style_check.py`、`check_deck.py` 目前也不查開場與結尾；各條「機械檢查」是給 50_檢查 重生 rules.yaml 時用的建議。
- **唯一出處**：同一件事在全指南只在一條規則寫等級與數字，其他檔只引用。本檔是以下主題的唯一出處：收尾張（OPEN-02）、學習目標張（OPEN-03）、封面格式（OPEN-04）、正常構造鋪底的份量（OPEN-07）、封面致謝行（OPEN-10）、結尾範圍張（OPEN-13）、封面不寫講次（OPEN-21）、條列大綱張（OPEN-22）、國考複習的定位位置（OPEN-30）。本檔引用別檔的唯一出處：divider 字級 `10_版面/12_字級.md` SIZE-18、封面字級 SIZE-19、無圖單句張字級 SIZE-32；問句的作答距離與頻率 `20_文字/26_語氣與態度.md` TONE-03；divider 字數 `30_結構/33_divider.md` DIV-03；段落末連放題數 `30_結構/34_國考題.md` EXAM-06；「國考重要性」判斷句 EXAM-45；備註裡的前後講銜接用語 `30_結構/36_備註.md` NOTE-09；古籍篇名當標題 `30_結構/35_中醫與古籍.md` TCM-08。
