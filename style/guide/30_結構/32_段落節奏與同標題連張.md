# 32 段落節奏與同標題連張

## 摘要

他不在一張投影片裡把一個主題講完，而是把主題拆成好幾拍，每一拍只改一個東西，而且多半改的是圖。去重後他自製的 9 單位（HISD，787 張）有 22.7% 的張落在逐字同標題的連張裡（family 算法 27.3%），連張六成是 2 張、最長 6 張；連張內相鄰兩張 86% 靠換圖、裁圖、移箭頭或 SmartArt 推進，最常見的一種是「文字整段不動、只換圖」（37/110），新增條列 3 行以上的只有 5%。同標題之外他還有三種一樣常見的拍法：同一張圖連放、每張標題換成下一句（41 對）；每張一句承接上一句的陳述句標題配一張圖的句子鏈（22 段）；並列子題用「主題：子題」或「X 1：」的標籤系列（14 組）。問句標題可有可無，用了就在同張或下一張回答；段與段之間放一張整張只有一句的過場句張（字級見 12_字級 SIZE-32）或名詞 divider，段長不等距（中位 7、四分位 4–19）；講一群病之前先放一小段正常組織學或前置複習；有三個以上分支時，講完一支回到總表把下一項改色；全套停在最後一個疾病，不做總結張，標題也不加（續）。逐步揭露全靠連張：39 份語料原檔 0 張設轉場，動畫時間軸只出現在影片張（RHY-35）。我的毛胚正好相反：標籤標題配三四行條列、相鄰兩張整組條列重寫（51%）、兩張都沒圖的連張、三步機轉塞進一行「=>」不拆張、同圖換標題 1 對、句子鏈 0 段。他改我的 B2 稿時多半只在我的節奏上補洞（他新做的連張 20 個轉換有 18 個靠圖），所以從零做新 deck 照他自製檔的節奏，改版時才對齊宿主 deck。2026-09 的牙醫系免疫 deck（課程 C，184 張，依他明令的一檔三節、每節約 60 張、40 分鐘講完、內文 28pt 製作，未經他改稿）把這些規則第一次全部上線：同標題比例（24.5%）、視覺推進（25/27）、無圖串（最長 6）、「=>」（全套 1 次）、不做總結、不加（續）都做到了，但連張的每一步都是「標籤標題不動＋整句換掉＋換一張圖（多半是從 Robbins 多面板圖裁出來的面板或節錄）」，文字凍結只換圖 0/27、同圖換標題 0 對、句子鏈 0 段、新增 3 行以上 8/27；主因是把他 2024 免疫課的句子標題鏈改寫成「名詞標題連放＋一句條列」（RHY-32），以及管線的 build 標記強迫組內標題逐字相同（RHY-30）。

**從零寫一段的順序（速查）**：

1. 段首：前置複習（該部位正常組織學；份量見 31_開場與結尾 OPEN-07；RHY-27），用一張過場句張或名詞 divider 開頭（RHY-13、RHY-14）。
2. 有 ≥3 個分支時先放一張總覽清單或樹（RHY-08、RHY-28）。
3. 每個分支或疾病：可以先放一張大字標題卡（RHY-11），再用 2–3 張同標題連張，每張只換圖或加一行（RHY-02、RHY-03、RHY-24）；並列亞型用標籤系列（RHY-05）。
4. 機轉：同一張圖連放、標題不動換說明或標題每張換一步（RHY-22 變體 A／B），或寫成 4–12 張句子鏈（RHY-23）；單行鏈最多 4 節，三步以上優先拆張（RHY-06）。
5. 分支講完：回到總表把下一項改色（RHY-20）；段尾可接國考題（題數見 34_國考題 EXAM-06；RHY-21）。
6. 全套：連續無圖不超過 6 張（RHY-12）；停在最後一個疾病，不做總結、不加（續）（OPEN-02、RHY-15、RHY-29）；不設轉場與動畫，逐步揭露一律做成連張（RHY-35）。

**改版（B2 改寫型，即 13_密度與字數 的沿用型）速查**：不要把整套改成自製節奏；照他改稿的補法：把純文字連張刪掉或補圖（RHY-16）、把一張列完的亞型拆成標籤系列（RHY-05）、在疾病段前補正常切片（RHY-27）、刪掉收尾呼應張（RHY-15）、把答案留到幾張之後的問句 divider 改成名詞 divider 或自答句（RHY-10、33_divider DIV-24）。divider 密度保留宿主 deck 的（RHY-14）。

**沿用他舊 deck（課程 C 型）速查**：先照他原段的拍法搬（RHY-32）：他是句子鏈就保留句子鏈、是標籤系列就保留前綴、是同圖移箭頭就保留同圖；明令的字級與中英對照照做，但不因此把他的標題句降成條列。管線上標籤系列不要標同一個 build（RHY-30）；節配額內做拆張（RHY-31）。
