# 中醫與古籍

## 摘要

授課教師把中醫古籍當成「細胞生物學以前的病理學」之一，和希波克拉底的體液說用同一種版式並列，不當課本外的補充，也不當中醫班的裝飾。他自製的 21 個獨有 deck 只有 5 個放古籍條文（簡介 16:9 新版與 4:3 舊版、發炎的桂枝湯證、細胞傷害的膿；發炎的桂枝湯張在兩個 deck 裡是同一張），另有發炎一開場用中醫概念詞「熱證」帶出紅腫熱痛；其餘講題（免疫、腫瘤、血液動力、各系統、國考複習、實驗課）正文一句古籍也沒有。這些元素跟著講題走、不跟著班別走：簡介與細胞傷害的古籍張在 A1、B1 各版逐字相同，發炎一的熱證開場在 A1、B1 與牙醫班 C 逐字相同，2025 年牙醫班 C 的簡介也放了 5 張古籍條文（immune/course.yaml 已確認 C＝牙醫三）。中醫班 B2 三套經他親手改稿後，每套只剩 1–2 個中醫元素，位置只有兩種：開場框架圖之前的古籍前提張，或某疾病臨床表現張之後的一題中醫臨床國考題；我放在中段與末段的古籍張 3/3 被整張刪除。放的時候，條文照文言原文抄、不夾英文；現代側只把條文字面所說的解剖、生理或症狀翻成現代名詞（水穀之道＝走食物的路、發熱惡風＝下視丘發燒），不從字面延伸推論病變，也不替寒熱、溫邪這類病機理論接機轉；內容章同一張一定寫出現代對應，簡介則先給一兩句古籍例證、再接「有分生以後可以解析」的轉折張。出處緊貼條文（正下方、篇名副標或「素問．五臟生成: 」句首），簡介帶作者與西元年代、內容章不帶，他親手打的古籍出處沒有一處放在左下 14pt「補充來源」；條文與內文同字級、維持內文色，要上色只上在現代側。正文不寫「古人已經知道」「與現代醫學一致」「沒有對應」「不作診斷依據」，也不用「古人」「古籍」「中醫」當總稱；他允許的評價只有技術史口吻與括號裡對方證的專業判斷，對古籍（也對希波克拉底）的嚴厲批評只出現在他自己的備註。2026-09 課程 C（immune）免疫疾病稿（184 張，我產、尚未經他改）照這些規則做成 0 古籍、0 中醫臨床題，兩輪審查共 335 條意見沒有一條涉及此事；它另外帶出兩個教訓：教師對某門課的字級與中英明令落到古籍時，條文與出處屬於學生要讀的字，不能掉到出處（credit）那一級（課程 C 的字級見 12_字級 SIZE-29），條文段也要豁免逐張中英檢查（TCM-32）；專案沒有中醫臨床題庫，中醫班要放題得先有可核對的題源（TCM-11）。

## 規則

### 讀法（先看）

- 引文一律逐字取自 `<materials>/corpus/decks/*.json`，格式「原文」（語料代號 #張號），已用 `scripts/verify_quotes.py` 核對；字級、色碼與註記寫在括號後面。
- 條文本身含「」時（例如頭頸部 #7 的四條 bullet），核對程式無法處理巢狀引號，本檔改為分段引用：條文一段、白話一段，各自附代號與張號；需要看整行原貌時用『』標示，『』內的文字不經程式核對。
- 『』也用來標示語料以外的文字：CLAUDE.md、記憶檔、immune 的 brief.md／course.yaml／glossary.md／待教師裁決清單、writer brief、審查紀錄、免疫成品。這些不在 `<materials>/corpus/`，無法逐字核對。
- 「↵」代表原檔同一段裡的軟換行（\v）；不換行空白以一般空格顯示。
- 簡稱（只用在敘述裡，引文後面一律寫完整代號）：「16:9 簡介」＝2025_A1_病理學簡介_0917、2026_B1_病理學簡介_0223、2026_A1_病理學簡介_0916 三份同內容檔，張號以 2026_A1 為準（2026_B1 號碼減 4）；「2025_C 簡介」＝2025_C_病理學簡介_0801；「發炎 #13」＝2025_A1_發炎二_0923 #13（＝2026_B1_發炎一_0323 #63）；「細胞 #30」＝2026_A1_細胞生物學與細胞傷害_0917 #30（＝2025_A1 #29＝2026_B1 #28）；「頭頸」＝2026_B2_頭頸部_0907；「呼吸一」「呼吸二」＝2026_B2_呼吸系統病理一_0913、二_0920；「KW」＝素問|靈樞|傷寒|金匱|溫熱論|難經|湯主之|湯證|脈證并治。
- 「古籍條文張」＝正文含 KW 條文的張；「古籍相關張」＝古籍條文張＋他自寫的文言提要張（頭頸 #8）＋中醫臨床國考題張（呼吸二 #83）；「中醫概念張」＝不引條文、但用中醫詞彙當框架的張（簡介的病因／病機／證、發炎一的熱證）。分母見〈統計表〉S1。
- 班別代碼：A1＝考醫師國考的班；B1＝中乙／後中（依 38_課別差異）；B2＝中醫系（本專案 ENT 與呼吸的中醫系版就是 B2 檔名）；C＝牙醫系三年級（『course_code: C # 教師用課程代碼命名檔案（C＝牙醫三）』，immune/course.yaml；immune/brief.md 同）；A2 未確認。本檔的「C 班」只指班別代碼 C 在 2025 年的各檔；2026-09 我產的免疫疾病課一律寫「課程 C（immune）」。
- **權威順序**（規則衝突時一律照這個順序裁決）：他親手改我的稿 ＞ 他自製 2026 ＞ 2025 ＞ 2024 ＞ 他對某門課的明令（只管那門課）＞ 我的毛胚（只當反例）＞ 他人（只當對照）。
- **「使用者（教師）2026-09 明令」**：他對某一班直接下的指示（目前只有課程 C（immune），牙醫系三年級免疫疾病，見 immune/brief.md 教師已裁決表與 immune/course.yaml）。在那一班照做；推到其他班時不算他的習慣，他的 deck 習慣優先。
- **「免疫稿經驗」**：我 2026-09 為課程 C（immune）產的免疫疾病稿（`immune/成品/病理學C_免疫疾病(PPTX)_20261002.pptx`，184 張）與兩輪審查（`immune/_archive/review/round1`、`round2`）的發現。這份稿還沒經他改，屬「我的毛胚」層，只能當反例與流程教訓，不能當他的正例；它不在語料裡，引用時寫 slug 或「第 N 張」，不用引文格式。
- 等級：MUST＝必須；NEVER＝禁止；SHOULD＝應該，偏離要有理由；AVOID＝避免，偶爾可以；MAY＝他用過、可選用。
- ID 沿用探勘版（<materials>/style_evidence/mining/35_中醫與古籍_final），其他指南檔（14_色彩 COL-07、16_出處 CITE-15、CITE-23、38_課別差異）的交叉引用都指這組號碼。TCM-32、TCM-33 是本版新增。`style/rules.yaml` v0 沒有任何 TCM 前綴的規則，本檔所有「機械檢查」都還沒進 rules.yaml，由 50_檢查 重生時加入。
- 本維度與其他維度重疊的地方：顏色細節以 14_色彩 COL-07 為準（深藍怎麼挑、Office 色盤陷阱）；出處通則以 16_出處 CITE-11、CITE-15、CITE-30 為準；整張去留以 37_刪張與留張 CUT-09 為準；班別差異以 38_課別差異 AUD-10 到 AUD-12、AUD-20 為準；備註裡的評價以 36_備註 NOTE-19 為準。
- **唯一出處**（同一件事只在一處定規則，其他檔一行引用，不另訂等級）：中醫班中醫元素的份量＝本檔 TCM-28（38_課別差異 AUD-25 引用）；古籍張的位置＝本檔 TCM-22 與 TCM-28（40_範例/41_他的原句庫 QUOTE-18 只管格式與字數）；中醫臨床國考題的版式＝34_國考題 EXAM-14（本檔 TCM-11、38_課別差異 AUD-09 引用）；投影片與 LLM 備註不寫貶抑評價＝本檔 TCM-10（26_語氣與態度 TONE-20、TONE-35 引用）；課程 C（immune）的字級＝12_字級 SIZE-29（本檔 TCM-32 只管古籍這一面）；「Robbins沒有篇幅講的事情」整張標題的上限與證據＝16_出處 CITE-23（本檔 TCM-18 只管古籍張不加眉標）；古籍出處不進左下「補充來源：」＝本檔 TCM-07（37_刪張與留張 CUT-17 的頁尾保留清單不含古籍）。

## 附錄 A：對新課的做法

### A1 中醫班（B2）新的器官系統 deck

- 份量：全套 1–2 個中醫元素（TCM-28）。先查他既有的 B2 三套有沒有同主題的古籍張，有就沿用他的字與版式。
- 位置：開場框架圖之前放 0–2 張古籍前提張，序號在前 10%（TCM-22、TCM-09）；或在某疾病臨床表現張之後放 1 題中醫臨床題（TCM-28；版式見 34_國考題 EXAM-14 與 TCM-11）。疾病段落中間不插古籍張，最後 10% 不放。
- 選條文：只選字面在講解剖、生理或症狀群的句子；優先張仲景系方證，《內經》只在字面講解剖時用（TCM-02、TCM-24）。不選要靠比喻才接得上病的句子（嬌臟、蓋、積）。
- 寫法：條文照通行本抄、不夾英文（TCM-13）；出處寫條列句首「素問．五臟生成: 」或上方副標「《靈樞．憂恚無言》」，不寫年代、不放頁尾（TCM-06、TCM-07）；現代側只翻字面，用「通氣(ventilation)：…」這類現代名詞開頭（TCM-31），結論行可用「A => B => C」或「…需要…，因此組織學上是…」（TCM-03）；條文 1–4 條、單條約 40 字內（TCM-14）；條文內文色、現代側可上本套深藍（TCM-04）。
- 標題：現代陳述句＋篇名副標，或篇名／方證直接當標題（TCM-08）；不用「古人」「古籍」「中醫」總稱（TCM-26），不加眉標與免責（TCM-18）。
- 下一張：可沿用同標題、拿掉條文、展開現代結論（TCM-23），再接框架圖。
- 字級：跟同張內文（TCM-15）；若該課有明令，照 TCM-32。
- 交付清單：條文異文、任何非語料來源的條文、他的舊張筆誤（待確認 3、4），一律列給他裁決；LLM 不自寫文言（TCM-21）。

### A2 非中醫班（醫學系、牙醫系、中乙／後中）

- 從零新寫的講題（免疫、腫瘤、血液動力、各系統）：古籍 0 張（TCM-19）。免疫稿就是照這樣做，兩輪審查沒有意見。免疫開場沿用他自己的定位張寫法「國考重要性：低」（2024_A1_免疫疾病一_1018 #2），比加古籍更貼近他。
- 沿用他的簡介、發炎、細胞傷害：他的古籍張與熱證張照原樣保留，不因班別刪也不加（TCM-33）；簡介範本用 16:9 新版（TCM-16），除非教師指定 4:3 舊版。
- 中醫臨床題不放；國考題依該班題庫（牙醫師或醫師），見 34_國考題。
- 講到 IL-1、TNF、PGE2 的發燒時不回扣桂枝湯證（TCM-20 例外；只有在他既有的發炎張裡才有這張）。

### A3 用 scripts 工具產古籍張（pool.md 寫法提醒）

- 出處寫在條列文字（句首「素問．五臟生成: 」）或篇名副標那一行，不要放 `<!-- src: -->`；該欄位會畫成左下 14pt「資料來源：」（TCM-07、TCM-32）。
- 條文不加任何 `[[色:…]]` 標記；現代側要強調時用 `[[藍:…]]`（對應 course.yaml `emphasis.藍`）（TCM-04）。
- glossary 逐張中英檢查若把條文段報錯，不要為了過檢查在條文裡補英文；把條文段豁免（比照國考題幹），或列給使用者改工具（TCM-13、TCM-32）。
- 中醫臨床題不能用 `<!-- quiz: key -->`（題庫沒有），標題格式也不是 course.yaml 的 `quiz_label`；在題庫與版型支援前，先列入待裁決，不自行產題（TCM-11）。
- 字級：產生器依 course.yaml `sizes`；古籍條文與出處用 `body`，不要落到 `credit`（TCM-32）。
