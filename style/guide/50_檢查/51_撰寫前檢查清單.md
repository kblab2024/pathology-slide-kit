# 撰寫前檢查清單

## 摘要

課程 C 的待教師裁決清單最後有 93 項，其中版面與格式偏好（國考題版式與正解色、出處位置、配色分工、Robbins 表格截圖或打字）幾項如果開工前問到，就不必事後大改。這份清單分五段：開工前要問他的事（每項附沒回覆時的預設）、要寫進 course.yaml 與 brief.md 的明令、撰寫前要備齊的素材、藍圖階段的檢查、撰寫每一批的自我檢查。每項寫出規則 ID 與執行的腳本；腳本都在 scripts/，Windows 上先設 `PYTHONIOENCODING=utf-8`。交付前的檢查在 52_交付前檢查清單.md。

## 規則

本檔不另立規則；以下每項是一個檢查動作，等級照所指的規則。依重要性排序：前面的項目沒做，後面做了也會白做。

### A. 開工前要問他的事（沒回覆時照「預設」做，並寫進待教師裁決清單）

1. **課程代碼、對象、上課日期與節數、每節講完的時間。** 預設：單講一檔 75–113 張，超過約 115 張先問是否拆講；每張約一分鐘。規則：38 AUD-14、AUD-34、31 OPEN-38（一檔多節）。記在 course.yaml 的 course_code、audience、lecture_date、decks.<deck>.sections／target／per_section。檢查：scripts/validate_blueprint.py（各節張數與分鐘）、scripts/check_deck.py 第 7 項（per_section）。
2. **有沒有底稿：這個講題他最近的一版在哪裡。** 預設：拿時間上最近的他本人檔整份沿用，班別差異只用五個動作；沒有底稿才從零做。規則：38 AUD-01、AUD-03、37 CUT-23。檢查：manual；衍生版完成後用 scripts/diff_decks.py 比對底稿（52 第 24 項）。
3. **這班考哪一種國考、放幾題。** 預設：A 班醫師國考每套 0–7 題；B 班不放醫師題，找得到對應時放一題中醫臨床題；課程 C 牙醫師題全套 10–15 題（明令）；其他 C 班課先問。規則：34 EXAM-01、EXAM-14、EXAM-23、EXAM-40、38 AUD-02。記在 course.yaml 的 decks.<deck>.exam、question_bank。檢查：check_deck.py 第 7 項（exam: false 卻有 quiz 張 → RED；key 不在題庫 → RED）。
4. **國考題的版式與正解色。** 預設：沿用底稿已有的國考張版式；從零做時擇一，甲式首欄正解字母粗體、不上色，乙式正解選項整段換本套強調色；題下說明行與 Robbins 原文頁二選一，未裁決前不兩種都做。規則：34 EXAM-03、EXAM-04、EXAM-05、EXAM-43、42 EDIT-32、14 COL-05。記在 course.yaml 的 decks.<deck>.quiz_style（甲／乙）、quiz_label 與 emphasis。檢查：manual（other_checks COL-05 未實作）。
5. **畫幅。** 預設：沿用該系列既有畫幅；新系列用 4:3（10×7.5 in），同一份不混用。規則：11 LAY-01。記在 course.yaml 的 slide.width／height。檢查：check_deck.py 第 1 項。
6. **字級有沒有明令。** 預設：沒有明令時，從零做的 4:3 照他自製版型（內建版面 placeholder 標題 44、內文 28 自然繼承，自拉文字方塊的句子 36、次選 30）；在既有 deck 改版照該 deck 的字級階層。有明令時照明令，只管該課。規則：12 SIZE-25、SIZE-06、SIZE-11、SIZE-29、01 AUTH-02。記在 course.yaml 的 sizes（沒有明令時的數值見 templates/course.template.yaml 的註解）。檢查：check_deck.py 第 3 項。
7. **中英對照的範圍。** 預設：每套第一次出現時給一次「中文(English)」；有明令「每張首見」時照明令並建 glossary。規則：24 TERM-01、TERM-07、TERM-34、TERM-35。記在 course.yaml 的 bilingual（first_per_deck＝預設；per_slide＝每張首見明令；off）、paths.glossary 與 bilingual_whitelist。檢查：scripts/style_check.py（per_slide 逐張比對；first_per_deck 算首見率，<70% WARN）、scripts/check_written.py（per_slide 時逐張比對，其他模式只查禁用變體）。
8. **正典與文獻範圍。** 預設：Robbins 11e 該章頁為唯一正典；文獻只補 Robbins 沒寫的、與本班相關的事實，句內附引文；衝突列清單。規則：01 AUTH-05、42 EDIT-29、38 AUD-33、16 CITE-10。記在 course.yaml 的 textbook 與 brief.md。檢查：manual（facts 查核）。
9. **出處放哪裡。** 預設：寫進該句或標題括號；管線的左下「資料來源：」列要不要保留，未裁決前沿用管線並列入清單。規則：16 CITE-10、CITE-11、CITE-01（允許不標）。檢查：manual（other_checks CITE-11 未實作）。
10. **關鍵字色與配色分工。** 預設：主題 accent2 橘 ED7D31 當本套唯一關鍵字色，每張 1–3 處，連同括號英文一起塗；紅只做單字級強調，每套 ≤4 張。規則：14 COL-02、COL-06、COL-13、COL-14。記在 course.yaml 的 emphasis。檢查：manual。
11. **古籍與中醫內容的去留。** 預設：非中醫班只有簡介、發炎、細胞傷害三講有他的先例，其他講題不放；中醫班每套 1–2 項、只放解釋型、放在前 10% 或一題中醫臨床題。規則：35 TCM-19、TCM-28、TCM-01、38 AUD-11。檢查：manual（other_checks TCM-09、TCM-19 未實作）。
12. **圖片來源與授權、借用同事的圖。** 預設：找得到就放，允許不標出處；借同事講義的圖在封面主標下加一行致謝，不逐張標；需要授權的列進清單，投影片不留佔位。規則：16 CITE-01、31 OPEN-10、15 IMG-02。檢查：manual；待補圖清單由 scripts/img_todo.py 產生。
13. **開場的評價句與國考統計由誰下判斷。** 預設：「國考重要性：X／臨床重要性：X」的判斷值由他下，生成端只放題數統計並列交裁決。規則：34 EXAM-45、38 AUD-06。檢查：manual。
14. **Robbins 表格貼截圖還是改原生表格。** 預設：照他的習慣貼截圖；課程有「學生要讀的字 ≥20」明令時，先切段、裁格，仍讀不到才改原生表格並列交裁決。規則：15 IMG-23、12 SIZE-30。檢查：manual。

### B. 寫進 course.yaml 與 brief.md 的項目

15. **把 A 段的回覆與預設逐項寫進 course.yaml 與 brief.md**：brief.md 要有「教師已裁決」表，每列有日期；course.yaml 每個數值都要對得到明令或語料規則，沒對到的列成問題。規則：38 AUD-34、01 AUTH-02。檢查：scripts/common.py 讀 course.yaml 時缺欄位即報錯；manual 核對。
16. **明令只寫在該課的 course.yaml、brief.md 與 glossary.md，不改 style/guide 的一般規則。** 規則：42 EDIT-44、01 AUTH-02。檢查：manual（新寫或修訂指南規則時，確認門檻沒有引用某一門課 course.yaml 的數值）。
17. **檔名與封面**：檔名寫課程碼不寫系名（病理學{碼}_{講題}(PPTX)_{YYYYMMDD}），封面「病理學：主題」、不署名、不寫第幾講。規則：38 AUD-05、31 OPEN-04、OPEN-01、OPEN-21。記在 course.yaml 的 decks.<deck>.filename 與 cover。檢查：rules.yaml OPEN-21（style_check）；OPEN-01 manual。

### C. 撰寫前要備齊的素材

18. **教科書頁圖與切圖。** `python render_pdf_pages.py …`、`python robbins_crop.py …`（見 scripts/README.md 一條龍流程第 1、2 步）。規則：15 IMG-14（Robbins 圖號寫法）、IMG-03（單圖尺寸）。
19. **他的舊投影片**：抽圖（`python extract_deck_images.py <舊.pptx> …`），並把可沿用的句子與已知錯誤列出來。句子逐字沿用、錯字照 TERM-18 的決策表、事實錯誤列清單。規則：41 QUOTE-39、24 TERM-18、01 AUTH-05。檢查：scripts/verify_quotes.py 可核對從語料抄來的句子；搬句的逐字比對 manual。
20. **事實帳**：Robbins 事實與文獻事實分開（`python merge_facts.py --course <課程>` → facts_R.json、facts_X.json、facts.md）。規則：01 AUTH-05、42 EDIT-11。
21. **glossary.md**（有中英明令的課必備）：一個概念一個中文正名、一個中文一個英文；禁用變體不得包含他親手寫過的字形；固定譯名照 24 的表。規則：24 TERM-35、TERM-02、TERM-33、23 BAN-22。檢查：style_check.py 讀 glossary；manual 核對禁用變體沒有誤殺他的寫法。
22. **國考題庫與選題**：題幹與選項逐字取自題庫 JSON；挑病理專屬、答案可由 Robbins 本章推得的題，避開「如附圖」而題庫沒有圖、答案為「#」或多答案的題。規則：34 EXAM-02、EXAM-41、EXAM-44（NFC）。檢查：check_deck.py 第 7 項（key 在題庫）；validate_blueprint.py（quiz key）。
23. **先決定這份 deck 的密度型**（單句型、條列型、沿用型），驗收時照該型的門檻。規則：13 DEN-24、DEN-01、DEN-03、DEN-04。檢查：manual（course.yaml 目前沒有 density_profile 欄）。

### D. 藍圖階段

24. **跑 `python validate_blueprint.py --course <課程> <blueprint.json> [--diagrams diagrams.yaml]`**：欄位、slug 唯一、圖檔存在、國考 key 在題庫、框架圖有定義、各節張數與分鐘、有圖率。RED 為 0 才往下。規則：15 IMG-01（有圖率）、37 CUT-33（張數預算是硬邊界）、34 EXAM-02。
25. **開場與結尾的張型**：不排學習目標、大綱、總結、Q&A、謝謝、參考文獻張；主題課從封面直接進主題；每一節停在最後一個內容張或該段的國考題。規則：31 OPEN-03、OPEN-22、OPEN-02、OPEN-05、16 CITE-17、33 DIV-14。檢查：rules.yaml OPEN-02、OPEN-03、OPEN-22、CITE-17（style_check 掃標題與段首）；末 3 張的檢查 manual。
26. **連張與段落節奏**：約兩到三成的張落在同標題連張或標籤系列；`<!-- build: 組名 -->` 只標逐字同標題的連張；機轉段落寫成句子鏈。規則：32 RHY-01、RHY-05、RHY-23、RHY-30、21 TTL-04。檢查：scripts/assemble.py（同一 build 組標題不一致 → RED）；make_batches.py 不拆 build。
27. **divider 寫名詞短語**，副標不寫講次、不寫摘要；多節 deck 節與節之間只用 divider 換段。規則：33 DIV-03、DIV-06、31 OPEN-38、OPEN-21。檢查：manual（other_checks DIV-06 未實作）。
28. **國考題放在所考內容後 1–2 張或段落收尾**，不集中到最後。規則：34 EXAM-06、38 AUD-07。檢查：manual。
29. **缺圖的張寫 `<!-- img_wanted: … -->`**，不畫佔位框；主題本來就不教才整張不產。規則：15 IMG-02、37 CUT-26。檢查：style_check.py（rules.yaml IMG-02）、check_deck.py 第 6 項。
30. **張數預算**：各節張數在 per_section 範圍；放不下時先在同節找可併或可移出選單的張，取捨寫進待裁決清單，不為守預算默默刪 Robbins 內容。規則：37 CUT-33、CUT-36、38 AUD-14。檢查：validate_blueprint.py、check_deck.py 第 7 項。

### E. 撰寫每一批的自我檢查

31. **跑 `python check_written.py --course <課程> --blueprint <bp.json> <batch.json>`**：rules.yaml 的 phrase／regex 規則、glossary 逐張中英、可見字元（>char_warn WARN、>char_red RED）、條列數（>3 WARN、>5 RED）、強調標記格式、Markdown 殘留、藍圖與批次的 slug 對應。RED 為 0 才交下一步。規則：rules.yaml 全部 rules 條目、13 DEN-02、DEN-10、24 TERM-34。
32. **標題與條列的句型**對照 41 原句庫找同類句，一張只講一件事；定義句把名稱放句尾「，稱為 X(English)」。規則：41 QUOTE-01、21 TTL-03、22 BUL-02、BUL-03。檢查：manual。
33. **禁用語與放行詞**：LLM 套語、雙破折、舞台指示、打氣 0；「其實」「不是 X，而是 Y」「因此」「求救、召喚」照用。規則：23 BAN-03、BAN-14、BAN-34、BAN-15、BAN-26、BAN-29、25 SYM-01。檢查：check_written.py、style_check.py（rules.yaml BAN-03g、BAN-14、BAN-34、SYM-01）。
34. **符號**：因果只用 ASCII「=>」，從零做的 deck 每張 ≤4 個、含「=>」的張 ≤10%；百分比半形緊貼；素材池 `<!-- … -->` 註解裡不寫「=>」或任何「>」（會截斷註解）。規則：25 SYM-04、SYM-08、22 BUL-06。檢查：style_check.py（SYM-04、SYM-08）；數量 manual（other_checks SYM-04 未實作）。
35. **備註（script.md 講稿）**：不寫張序指涉（投影片 N｜、上一張、下一張）、不寫給他的備忘與審查術語；事實與投影片一致；學生要看的東西不只放在備註。規則：36 NOTE-03、NOTE-29、NOTE-30、NOTE-31、NOTE-02、23 BAN-35。檢查：style_check.py（NOTE-03、BAN-35 的 notes 範圍）。
36. **搬他的舊句**：逐字沿用；只准補明令要求的英文、與 Robbins 衝突時的最小改寫、英文拼字改正；每一處改動列清單。規則：41 QUOTE-39、24 TERM-18、38 AUD-35。檢查：scripts/verify_quotes.py 核對引句；pool 行與他原句逐字比對 manual。

## 常見錯誤

1. 開工前只問內容範圍，沒問國考題版式、出處位置與配色，做完才發現要整套改。→ A 段第 4、9、10 項。
2. 把課程 C 的 course.yaml 複製給新課程後沒改字級與中英規則，讓明令擴散到別的課。→ 第 6、7、16 項。
3. 沒有找他的舊版就從零寫，結果他的句子、錯字處理與版式都對不上。→ 第 2、19、36 項。
4. glossary 的禁用變體把他親手寫過的字形列進去（「天皰瘡」），讓檢查器擋他的寫法。→ 第 21 項。
5. 藍圖裡先排了學習目標、大綱、總結張，撰寫時才刪，張數預算跟著亂。→ 第 25、30 項。
6. 素材池的國考說明行寫「A => B」，「>」把註解截斷，說明行少一半。→ 第 34 項。
7. 為了守每張字元上限，把定義或正解移進講稿。→ 第 35 項、36 NOTE-31。

## 待教師確認的問題

本檔的「預設」就是沒回覆時的做法；需要他回答的題目集中在 00_README.md「待教師確認的問題」與各課的待教師裁決清單。新課程開工時，把 A 段 14 項整理成一頁問他，上課前最好先回的放最前面（38 AUD-36 的格式）。
