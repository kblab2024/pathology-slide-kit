# 課程簡報（brief）範本

> 複製到 `<教材庫>/courses/<課程名>/brief.md` 後填寫。所有工作流代理（lecture-gather、lecture-blueprint、lecture-write、lecture-review、style-mining 的 Brief）開工前都先讀這份，所以寫「決定」與「限制」，不寫過程。
> 教師明講過的事寫進「教師已裁決」並附日期；還沒問到的寫進「待教師確認」，不要自己假設成決定。
> 不寫本機絕對路徑、學生資料、教學評量資料；素材位置一律寫相對於課程資料夾或教材庫的路徑。
> 範例值取自 2026-09 牙醫系「免疫疾病」課程（課程代碼 C）。

## 1. 對象與時間
- 系級與課程代碼：例「牙醫系三年級（課程代碼 C）」。
- 上課日期、節數、每節分鐘：例「2026-10-02（五）上午 9–12，三節，每節 50 分鐘」。
- 授課教師。
- 這班去年拿到什麼（沿用哪份舊 deck、缺哪些主題），今年要補什麼。
- 學生另外修過或同時修的相關課（決定哪些內容只複習）：例「另有口腔微生物與免疫學，正常免疫只複習」。

## 2. 教師已裁決
用表格，一列一個決定，附裁決日期。至少涵蓋下列項目；沒有明令的項目依 `style/guide/`，不要自行發明。

| 項目 | 決定（範例） |
|---|---|
| 檔案與畫幅 | 一個 4:3 PPTX 涵蓋三節，約 180 張（每節 55–65 張） |
| 節奏 | 每節以 40 分鐘講完為目標，約 40 秒一張；同標題連張、純圖張走得快 |
| 國考題 | 題庫（牙醫師／醫師／中醫師／不放）、全套題數、每節題數、就近放在該主題後 1–2 張；版式甲或乙（course.yaml `decks.<deck>.quiz_style`） |
| 複習範圍 | 例：正常免疫精簡複習 10–15 張，只講後面疾病會用到的 |
| 事實來源 | 唯一正典教科書與章節頁碼（例 Robbins 11e 第6章 pp.167–235）；文獻只補充什麼、必引出處、不得蓋過教科書；衝突列清單交教師 |
| 文字 | 不可 LLM 語；術語中英規則（例：所有專有名詞每張「中文(English)」＝course.yaml `bilingual: per_slide`；沒有明令＝每套首見一次 `first_per_deck`） |
| 字級 | 例：標題 36、內文 28、學生要讀的字 ≥20、只有出處 14（同步寫進 course.yaml sizes） |
| 圖 | 有圖率目標、可用的圖源（教科書圖、他的舊投影片、開放授權圖）、他人圖片的致謝方式 |
| 中醫與古籍 | 中醫班才需要：古籍放哪裡、放幾條 |

## 3. 大綱草案
依節列出段落與目標張數（藍圖會細化）；每段寫主題、目標張數、要用的教科書圖表、要補的文獻主題、國考題位置。例：

**第一節：正常免疫複習與過敏（約 60 張）**：封面與開場 2（考試份量的直白數據）｜正常免疫 10–12｜過敏總論 3（Table 6.1）｜第一型約 11（文獻：局部麻醉藥真過敏罕見）｜第二型約 8｜第三型約 7｜第四型約 9｜國考題 3–5。

## 4. 素材位置（相對於課程資料夾或教材庫）
- 教科書頁圖與 OCR：course.yaml `textbook.pages_dir`（印刷頁＝PDF 頁＋`page_offset`）。
- 事實帳：`facts/facts_R.json`（教科書）、`facts/facts_X.json`（文獻）、人讀版 `facts/facts.md`。
- 圖：`assets/images/` 下各資料夾（教科書切圖、舊投影片抽圖、文獻圖），各附 `圖片清單.md` 或 `*_images.json`。
- 國考題：`<工具包>/question_banks/<題庫>/`；候選與推薦 `_archive/gather/exam/exam_candidates.json`。
- 蒐集設定：`gather.json`（範本 `<工具包>/templates/gather.template.json`）。
- 風格：`<工具包>/style/guide/`；本課撰寫 brief（若有）`<教材庫>/style_evidence/writer_brief_<課程名>.md`。

## 5. 教師的舊教案要點（可沿用的他自己的聲音）
- 他在同主題舊 deck 裡的原句（附 deck 代號與張號，例「先天免疫『不用辨識抗原』有兩種方式」（2024_A1_免疫疾病一_1018 #n））。
- 舊 deck 裡哪幾張是他自製、哪幾張是別人的舊張（只沿用他自己的）。
- 舊張的已知錯誤（重用時要改，並列入待教師裁決清單），例：路徑名稱寫錯、國考題年度寫錯。

## 6. 待教師確認
- 列出還沒問到、會影響張數或內容的問題，每題附「沒回覆時的預設」。例：「畫幅要不要改 16:9？預設沿用 4:3」。

## 7. 交付物
- 成品檔名（依 course.yaml `filename`）、PDF、`成品/待補圖清單.md`、`成品/待教師裁決清單.md`。
